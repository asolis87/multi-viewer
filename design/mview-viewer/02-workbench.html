    orders-service

    Handles checkout, order state and payment capture for the storefront.

    Checkout flow

    The storefront never talks to the payment provider directly. Every order goes through the gateway, which forwards it to orders-service.

    Endpoints

    MethodPathPurpose
    POST/ordersCreate an order from a cart
    GET/orders/:idRead order state
    POST/orders/:id/cancelCancel before capture

    Try it locally

    # create an order
curl -X POST localhost:8080/orders \
  -H "content-type: application/json" \
  -d '{"cartId": "cart_19ab", "currency": "EUR"}'
